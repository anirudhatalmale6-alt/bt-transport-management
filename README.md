# BT Transport Management — WordPress Theme

A modern one-page WordPress theme for BT Transport Management (External Transport Manager & compliance consultancy).

## Features
- Modern single-page design (hero, services, services flyer pop-up, approach, about, enquiry form)
- **Editable via Appearance → Customize:** logo, services flyer image, YouTube training channel link, phone, email, and the inbox that enquiries are sent to
- Built-in enquiry form (name, company, email, phone, topic, message) that emails submissions to your inbox via `wp_mail` — with nonce + honeypot spam protection
- Responsive / mobile-friendly

## Install
WordPress admin → Appearance → Themes → Add New → Upload Theme → choose the zip → Activate.
Then set your front page to display the homepage and fill in the details under Appearance → Customize → "BT Transport — Content & Contact".
